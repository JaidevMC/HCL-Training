Agile/Scrum Basics

Sprint:
A fixed period in which the development team completes planned work.

Daily Standup:
The team discusses:
- What was done yesterday
- What will be done today
- Any blockers

Retrospective:
The team discusses what went well, what did not go well, and what can be improved.

User Story:
A requirement written from the user's point of view.

Format:
As a [user], I want [feature], so that [benefit].

Definition of Done:
- Requirement is understood
- Code is completed
- Testing is completed
- No critical bugs
- Code is reviewed
- Documentation is updated
- Changes are committed and pushed
